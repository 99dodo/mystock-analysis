把 Claude 產出的股票分析 HTML，推上 GitHub Pages，變成永久連結

Phase 1 第一階段：基礎建設（只做一次）

1

建 Repo

網址：https://github.com/new
Repository name：mystock-analysis
選 Public + 勾 Add a README file → Create repository

https://github.com/99dodo/mystock-analysis你的倉庫
2

開 GitHub Pages

進到 Settings → Pages → Source 選 Deploy from a branch → Branch 選 main / (root) → Save

等 1-2 分鐘，永久網站生效：
https://99dodo.github.io/mystock-analysis/

Phase 2 第二階段：Token 金鑰 ⚠️ 最重要

Token = 你家鑰匙，拿到可改你所有檔案。設定錯會被駭。
3

建 Token

網址：https://github.com/settings/tokens?type=beta → 點綠色的 Generate new token

  • Token name：99dodo-mystock-push（讓你以後知道這是幹嘛的）
  • Expiration：選 90 days 就好，到期再重產生，比較安全
  • Description：可不填
4

選倉庫（最重要，不要選全部）

  • Resource owner：選 99dodo
  • Repository access：選 Only select repositories
  • 下面下拉，只勾 mystock-analysis，其他都不要勾
這樣就算 Token 外洩，別人也只能動這一個倉庫，不能動你別的倉庫。
5

選權限（最小權限）

往下滑到 Permissions → Repository permissions，只開這兩個就好，其他都保持 No access：

  • Contents：選 Read and write（才能 push html 上去）
  • Metadata：它會自動變 Read-only，不用理它
6

產生並複製 Token

按最下面的 Generate token，產生後會給你一串 github_pat_xxxxxx，按旁邊的複製圖示複製起來。

注意：這頁關掉就看不到 Token，要馬上複製貼給 Claude 用。

Phase 3 第三階段：改 SKILL.md ⚠️ 有地雷

原本：https://github.com/{your-username}/{your-repo} 改成：https://github.com/99dodo/mystock-analysis 原本：http://{your-username}.github.io/{your-repo}/ 改成：http://99dodo.github.io/mystock-analysis/
地雷：中間不能有空格！
錯誤：https://github.com/ 99dodo/...（有空格會 401 失敗）
正確：https://github.com/99dodo/...

Phase 5 第五階段：收尾

11

Token 怎麼處理

方案 A（最安全）：用完即丟 - 做完馬上回 Token 設定頁按 Delete，下次再建
方案 B（你現在用的）：留 90 天 - 90 天內跑別檔共用，到期自動失效，之後照 Phase 2 步驟重新產生一組即可

🔴 絕對不能做的事

❌ 把 github_pat_... 貼到 Facebook、Line、公開社團
❌ 把 Token 上傳到 GitHub 檔案裡
❌ 設成 No expiration 或 All repositories

不小心貼出去了？馬上到 Token 設定頁按 Delete，刪掉就立刻失效。
