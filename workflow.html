Phase 1 第一階段：GitHub 基礎建設 只做一次

1

建 Repo

網址：https://github.com/new

  • Repository name：mystock-analysis
  • 選 Public + 勾 Add a README file
  • 按 Create repository
https://github.com/99dodo/mystock-analysis你的倉庫
2

開 GitHub Pages

進到：Settings → Pages

  • Source：Deploy from a branch
  • Branch：main / /(root) → 按 Save
等 1-2 分鐘，你的永久網站就生效：
https://99dodo.github.io/mystock-analysis/ — 這是你的總目錄

Phase 2 第二階段：Token 金鑰 ⚠️ 最重要，特別注意

Token = 你家鑰匙 + 提款卡密碼，拿到的人可以改你所有檔案。設定錯會被駭。
3

建 Token

網址：https://github.com/settings/tokens?type=beta → 按 Generate new token

  • Token name：claude-temp-7days（好認就好）
  • Expiration：7 days ⚠ 不要選 No expiration
  • Repository access：Only select repositories → 只勾 99dodo/mystock-analysis ⚠ 不要選 All
4

設權限 地雷區

往下滑到 Permissions → Repository permissions → Contents

  • 選 Read and write 不要選 Admin，不要全開
  • 其他權限全部保持 No access
為什麼只開 Contents？開 Admin 別人就能刪你 Repo，開 Workflows 別人能塞病毒。最小權限最安全。

按 Generate token → 複製綠色框裡 github_pat_... 那一長串

注意：這一頁關掉就看不到 Token 了，要馬上複製起來，貼給 Claude 用。

Phase 3 第三階段：改 SKILL.md ⚠️ 有地雷

5

改 SKILL.md

打開 SKILL.md 搜尋並替換：

原本：https://github.com/{your-username}/{your-repo} 改成：https://github.com/99dodo/mystock-analysis 原本：http://{your-username}.github.io/{your-repo}/ 改成：http://99dodo.github.io/mystock-analysis/
⚠️ 地雷：中間不能有空格！
錯誤：https://github.com/ 99dodo/... ← 中間多一個空格
正確：https://github.com/99dodo/...

之前你貼成有空格的，push 會直接失敗 401。這是最多人卡關的地方。

Phase 5 第五階段：收尾 + 安全守則

10

Token 怎麼處理

方案 A（最安全）：用完即丟
做完馬上回 Token 設定頁 按 Delete 刪掉，下次跑新股票再建一顆。
方案 B（你現在用的，方便）：留 7 天
7 天內跑別檔都用同一顆，8/11 自動過期，過期前 GitHub 會寄信提醒。

🔴 絕對不能做的事 最高危險

  • ❌ 把 github_pat_... 貼到 Facebook、Line、公開社團、PTT、Dcard
  • ❌ 把 Token 上傳到 GitHub 檔案裡面（Claude 不會，別自己手動上傳）
  • ❌ 設成 No expiration 或 All repositories 權限
  • ❌ 截圖問問題時，截到完整 Token

如果不小心貼出去了怎麼辦？馬上到 Token 設定頁按 Delete，刪掉後那串就立刻失效，別人拿到了也沒用。
