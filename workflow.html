流程整理

2. 開 Pages: Settings → Pages → main / root → Save → 等 1 分鐘 → 99dodo.github.io/mystock-analysis/ 生效

3. 產生 Token: Settings → Developer settings → Fine-grained tokens → Token name: claude-temp-7days, 選 7 days, Only select repositories: 99dodo/mystock-analysis, Permissions: Contents Read and write

4. 改 SKILL.md: 把 {your-username}/{your-repo} 改成 99dodo/mystock-analysis，注意不能有空格！

5. Claude 執行: 新對話上傳 SKILL.md，貼上 Repo + Token + 要分析的股票代號如 6202
