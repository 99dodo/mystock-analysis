重點提示： 2025年(114年度) 營業現金(A) 13.30億 略低於 稅後淨利(D) 13.74億，口袋收到的錢比帳面賺的錢少一點，但差距不到5%，非暴增缺口。存貨與合約負債同步成長(存貨+7.5%、合約負債+20.2%)，沒有出現背離。真實股利覆蓋率 0.92，略低於1，但融資活動顯示公司是「還債」而非「借新債發股利」，用的是帳上現金存量。

八大現金流解讀規則

規則專業定義實務解讀(強制三段)核心公式數字判斷
規則一
A<D 應收暴增		 營運現金流入小於稅後淨利，需檢查是否為應收帳款堆積所致 2025年 營業現金(A) 13.30億 略低於 稅後淨利(D) 13.74億，差距約0.44億(3.2%)，帳面賺的錢大部分都真的收到現金了。

公式對照：應收/營收比 = 應收帳款 / 近12月營收。2025年底 應收帳款 12.40億 / 全年營收 102.75億 = 12.07%，2024年底為11.56%，僅小幅上升，並非暴增。

影響：A<D缺口小且非應收帳款驅動，對股利/成長影響有限，屬正常業務波動。 		應收/營收比 = 應收帳款餘額 / 近12月營收 2025: 12.07%
2024: 11.56%
2026H1(TTM): 11.38%		 正常，比率穩定未暴增
規則二
A<D 存貨暴增		 獲利被存貨積壓吃掉，檢查存貨成長是否遠超營收成長 2025年 存貨 17.69億，比2024年的 16.46億 增加7.48%，同期營收成長7.02%，兩者幾乎同步，貨沒有明顯堆在倉庫裡。

公式對照：存貨YoY vs 營收YoY。2026年6月底存貨較去年同期僅增3.47%，而同期營收成長6.44%，存貨成長甚至低於營收成長，屬去化健康。

影響：A<D的缺口不是存貨造成的，不影響對明年備貨/成長判斷。 		存貨YoY vs 營收YoY 2025: 存貨+7.48% / 營收+7.02%
2026H1: 存貨+3.47% / 營收+6.44%		 正常，未暴增
規則三
B大於A / 資本支出折舊比		 投資過度或吃老本，比較資本支出與折舊費用 2025年 投資活動淨流出(B) 4.16億，遠小於 營業現金(A) 13.30億，公司賺的錢遠多於花掉的投資錢，不是花錢比賺錢快。

公式對照：資本支出/折舊比 = 取得不動產廠房設備 / 折舊費用。2025年 3.84億 / 2.07億 = 1.86倍，>1.5屬於「擴產」訊號；2024年為1.41倍，屬正常維護規模；2026上半年降回1.02倍。

影響：2025年擴大資本支出對應營收成長7%，是合理的產能布建，非過度投資的警訊。 		資本支出/折舊比 = B取得不動產廠房設備 / 折舊費用 2025: 1.86倍
2024: 1.41倍
2026H1: 1.02倍		 2025年擴產，非吃老本
規則四
C持續正		 融資活動現金流是否持續為正，檢查股本、商譽變化 9911櫻花近10年的 融資活動現金流(C) 幾乎年年為負：2025年-11.60億、2024年-7.27億、2023年-7.48億，代表公司是「還錢+發股利」給股東和銀行，而不是靠借錢或增資撐營運。

公式對照：C持續負主要由「發放現金股利」構成(2025年支出中現金股利占大宗)，短期/長期借款則呈現淨償還(短期借款淨變動約-0.53億、長期借款淨變動約-0.23億)，非淨舉債。

影響：這是成熟配息型公司的典型現金流結構，不是財務吃緊的訊號。 		觀察C正負與股本、商譽變化 2025: C -11.60億
2024: C -7.27億
2023: C -7.48億		 持續負，屬正常還債配息
規則五
自由現金流FCF		 真能拿來發股利的錢，扣掉資本支出後的營業現金 2025年 FCF = 營業現金(A) 13.30億 - 資本支出 3.84億 = 9.45億，代表公司在花完該花的設備錢後，還有這麼多現金可運用；2024年FCF為9.46億，兩年相近。

公式對照：FCF = A - 資本支出(取得不動產廠房設備)。三表齊全下可算出真實FCF，非用損益表獲利粗估。

影響：FCF約9.45~9.46億，將在規則八用來檢驗股利發放的永續性。 		FCF = A營業現金流 - 資本支出 2025: 9.45億
2024: 9.46億		 穩定，兩年相近
規則六
應收/營收比		 收現能力，貨出去了錢收不回來的風險 2025年底 應收帳款 12.40億 占全年營收(102.75億)的 12.07%，2024年底為11.56%，2026年6月底(以近12月營收計)為11.38%，比率在11~12%間微幅波動。

公式對照：應收/營收比 = 應收帳款 / 近12月營收，遠低於20%警戒線，且未見持續上升趨勢。

影響：收現能力穩定，不是拖累A<D的主因。 		應收/營收比 = 應收帳款 / 營收 2025: 12.07%
2024: 11.56%
2026H1(TTM): 11.38%		 正常(<20%且無上升趨勢)
規則七
存貨 vs 合約負債背離		 備貨是客戶先付錢，還是自己猜景氣，用存貨YoY對照合約負債YoY 2025年 存貨 較2024年增加7.48%，同期 合約負債(客戶預付款/未出貨訂單)從2.64億增至3.17億，成長20.19%，合約負債成長幅度還高於存貨，代表備貨背後有更多客戶訂單/預收款支撐，不是自己猜的。

公式對照：存貨YoY vs 合約負債YoY。若出現「存貨↑+合約負債↓」才是背離警訊；本案為「存貨↑+合約負債↑，且合約負債漲更快」，屬於正向訊號。2026年6月底同樣呈現存貨+3.47%、合約負債+6.23%，同步上升。

影響：備貨動作有訂單支撐，對明年營收動能是正面訊號，非景氣誤判。 		存貨YoY vs 合約負債YoY 2025: 存貨+7.48% / 合約負債+20.19%
2026H1: 存貨+3.47% / 合約負債+6.23%		 正常，同步成長無背離
規則八
股利永續/真實股利覆蓋率		 股利是真賺的還是借來發的，用FCF衡量能否不借錢發幾次 2025年公司實際發放的現金股利為 10.28億(2025年內以現金支付，對應2024年獲利)，同年 FCF為9.45億，覆蓋率為 0.92，代表當年帳上現金流入略不足以完全覆蓋當年配發的股利。

公式對照：真實股利覆蓋率 = FCF / 現金股利。2024年覆蓋率為 9.46億 / 8.49億 = 1.11(健康)；2025年降到0.92，<1，觸發留意，但檢查同期融資活動：短期+長期借款均為「淨償還」而非「淨舉債」，代表缺口是用帳上現金存量補足(期末現金餘額由24.09億降至21.57億)，而非借新債發股利。2026年6月已再支付11.00億股利(對應2025年獲利)，全年FCF覆蓋率需待下半年數據確認。

影響：目前屬於「動用現金儲備」而非「借錢配息」，程度尚溫和，但若覆蓋率連續多年<1、現金餘額持續下滑，就要重新評估股利政策的永續性。 		真實股利覆蓋率 = FCF / 現金股利 2024: 1.11
2025: 0.92
2026(待確認全年)		 2025年<1，需留意，但非借新債發股利
