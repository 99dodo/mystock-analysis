規則二

規則三
資本支出強度(B大於A)		 投資活動現金流出是否遠超營業現金流入(擴產或吃老本) 2025年投資活動(B)淨流出12.30億，是當年營業活動(A)淨流入7.03億的1.75倍；2024年投資流出13.33億更是營業流入5.16億的2.58倍，代表這兩年花在買地買設備的錢，遠比本業賺回來的現金多。

公式對照：資本支出/折舊比 2025年2.80倍、2024年3.72倍，皆遠高於1.5倍門檻，屬於「積極擴產」而非「吃老本」，但擴產規模持續超出本業現金承載能力，需靠外部資金補缺口(見規則四)。

影響：若擴產(不動產廠房及投資性不動產大增)未來能轉化為營收成長屬合理策略投資；但2025年營收已衰退4.7%(規則二)，擴產效益尚待驗證，直接牽動規則五FCF與規則八股利能力。 		資本支出/折舊比 2025: 2.80x
2024: 3.72x		 需觀察
規則四
融資依賴(C持續正)		 是否連續多年靠借款/增資撐現金流 從Goodinfo近5年數據看，融資活動(C)在2022、2023、2024、2025連續4年都是正值(4.09億→4.56億→6.71億→5.17億)，代表這4年公司每年都在淨舉債，不是靠賺錢的現金在過生活。

公式對照：C連續正值搭配規則三資本支出/折舊比持續>1.5倍，兩者互相印證——聲寶這幾年的擴產，主要是借錢撐起來的，不是本業現金撐起來的。

影響：只要擴產有明確回報可接受；但若效益遲遲未反映在營收，持續舉債會推升利息負擔——2025年財務成本1.07億，較2024年0.63億增加71%，正在侵蝕獲利。 		C是否連續3年為正 2022~2025
連續4年為正		 需觀察
規則五
自由現金流(FCF)		 真正能拿來發股利、還債的閒錢 2025年FCF = 營業現金(A)7.03億 - 資本支出12.62億 = -5.59億；2024年FCF = 5.16億 - 13.71億 = -8.55億，連續兩年都是負值，代表本業賺的現金完全不夠支應買地買設備的資本支出，還倒貼。

公式對照：FCF = A(規則一) - 資本支出(規則三)，2025年缺口比2024年收斂約35%，主要受惠於A成長36%及資本支出略減8%的雙重改善。

影響：FCF連續兩年為負，直接決定規則八「真實股利覆蓋率」必為負值——近兩年的現金股利並非本業現金賺來發的，這是本次分析最重要、也是一般消息面最容易忽略的一點。 		FCF = A - 資本支出 2025: -5.59億
2024: -8.55億		 不通過
規則六
應收/營收比		 收現能力：貨出去了錢有沒有真的收回來 2025年底應收帳款5.84億，占2025年營收90.50億的6.45%；2024年底應收帳款9.03億，占2024年營收94.94億的9.51%，占比明顯下降。

公式對照：應收/營收比從9.51%降到6.45%，遠低於20%警戒線，且呼應規則一A<D缺口收斂的現象——收現能力2025年確實在改善。

影響：收現能力轉強對維持營運資金水位有正面幫助，是這次分析中少數的正向訊號，值得在2026年後續季度持續追蹤是否延續。 		應收帳款/營收 2025: 6.45%
2024: 9.51%		 優秀
規則七
存貨vs合約負債背離		 備貨是真有訂單撐腰，還是自己在賭景氣 2025年底存貨年減11.5%(16.60億→14.69億)，同時合約負債(客戶預收款)年增36.1%(2.07億→2.82億)，存貨在減少、客戶預收款卻在增加，是一降一升的健康搭配，不是背離。

公式對照：本規則公式為存貨YoY vs 合約負債YoY，聲寶兩者方向相反且都朝健康方向走，與規則二存貨去化的結論互相印證。2026H1(2026/6/30對2025/6/30)同樣呈現存貨YoY -12.6%、合約負債YoY +15.2%的一致模式。

影響：出貨去化的同時還有客戶願意預付訂金，對短期營運動能是正面訊號；但仍須留意這是否集中在少數大客戶（家電代工類常見大單模式），第3步法說會可進一步確認客戶結構。 		存貨YoY vs 合約負債YoY 存貨YoY -11.5%
合約負債YoY +36.1%		 良好
規則八
股利永續(真實覆蓋率)		 股利是真賺的還是借來發的 2025年真實股利覆蓋率 = FCF(-5.59億) / 現金股利(5.45億) = -1.03倍；2024年 = -8.55億 / 5.45億 = -1.57倍，兩年皆為負值，代表這兩年發的現金股利，帳面上完全不是靠自由現金流發出來的。

公式對照：規則五FCF連兩年為負，加上規則四C連4年為正(2025年融資活動淨流入5.17億)，三者合起來的完整故事是：聲寶2024、2025年的現金股利，很大程度上是靠當年度新增的借款/票券撐起來的，屬於典型的借錢配息。

影響：只要公司持續借新還舊且營運穩定，短期股東仍可領到股利；但若未來融資環境緊縮或營收持續衰退(規則二)，股利政策的可持續性會直接受到考驗，是存股族最需要留意的風險點。 		FCF / 現金股利 2025: -1.03倍
2024: -1.57倍		 不通過
